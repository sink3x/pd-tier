# pd-tier

Учебный тир-лист для курса «Проектная деятельность» (ПД ТОП-ИТ). Открывается с телефона: https://sink3x.github.io/pd-tier/

Два набора карточек:

- **Ошибки на выступлении** — 24 ошибки, которые нужно разложить по тирам: A (грубая), B (заметная), C (мелочь). Ссылка: https://sink3x.github.io/pd-tier/
- **Важность дефектов** — 14 дефектов учебного приложения из [pd-bug-bash](https://github.com/sink3x/pd-bug-bash): критично, важно, желательно. Ссылка: https://sink3x.github.io/pd-tier/?set=bugs

## Как пользоваться

1. Нажмите на карточку, потом на тир. На компьютере карточки можно перетаскивать.
2. Нажмите «Сравнить», чтобы увидеть, где ваш вариант расходится с ключом.
3. «Скопировать ссылку на мой вариант» сохраняет раскладку в ссылке. Блок «Свод группы» внизу собирает несколько таких ссылок и показывает, как голосовала группа.

Сайт — один файл `index.html` без сборки и без сервера. Раскладка хранится в браузере и в ссылке. Сцены в папке `scenes` нарисованы для курса и лежат в SVG.
